# Code of conduct

Sift exists to make people's phones lighter without taking advantage of them. The same applies to the people who build it.

## Expected

- Be direct, kind and specific.
- Critique the code and the decision, not the person.
- Assume good faith and ask before rewriting someone's work.
- Respect privacy: never post personal photos, contact data or device identifiers.
- Give newcomers room to learn.

## Unacceptable

- Harassment, discrimination, threats or sexualised attention.
- Publishing private information without consent.
- Deliberately adding trackers, dark patterns or misleading claims to Sift.
- Hostile or dismissive review comments.

## Enforcement

Maintainers may edit, lock or remove contributions that violate these rules and may block repeat offenders. Report concerns privately to the maintainers through the repository's security advisory channel.

This is a short, readable code of conduct, not a legal document.
